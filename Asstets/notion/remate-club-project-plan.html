Remate Club

Plan rada za production-quality full-stack aplikaciju za pronalaženje padel klubova, pregled termina i kreiranje rezervacija.

Backend-first Spring Boot + React JWT auth Booking safety

Project Goal

Remate Club je full-stack aplikacija za igrače, vlasnike klubova i administratore. Prvi cilj je stabilna osnova projekta, zatim sigurni auth tokovi, pa tek onda clubs, courts i booking engine.

MVP foundation first
Players Browse clubs, view availability, create and manage reservations.
Club Owners Manage clubs, courts, schedules, prices, blocked periods, and reservations.
Administrators Approve clubs and manage platform-level resources.

Backend Foundation

Primary focus

Core Modules

  • auth - registration, login, refresh, current user
  • user - user entity, roles, statuses
  • security - JWT validation and authorization
  • common - config, exceptions, response model

Auth Endpoints

  • POST /api/auth/register
  • POST /api/auth/login
  • POST /api/auth/refresh
  • GET /api/auth/me

Booking Conflict Rule

Critical business logic

Nova rezervacija se preklapa sa postojećom rezervacijom ako važi sledeći uslov:

existing.startAt < requested.endAt
AND
existing.endAt > requested.startAt

Booking kreiranje mora biti u database transakciji, uz proveru aktivnog terena, odobrenog kluba, blokiranih termina i postojećih aktivnih rezervacija.

Do Not Do In First Cycle

Scope control
  • Do not implement the full booking engine.
  • Do not implement all frontend pages.
  • Do not add payments.
  • Do not add email verification flow.
  • Do not create admin accounts through public registration.
  • Do not rely on Hibernate to create production tables.
  • Do not return JPA entities from controllers.

Definition Of Done

Quality gate
  • Code compiles
  • Relevant tests pass
  • API does not expose JPA entities
  • Security rules are enforced
  • Errors return consistent JSON responses
  • README/docs are updated if setup or API changed
  • No placeholder business logic exists in critical backend paths
  • Commands and failures are reported clearly
